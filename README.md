# EVERY8D 簡訊發送工具

EVERY8D 簡訊發送工具是一套基於 AutoHotkey 開發的 Windows 桌面應用程式，專為透過 EVERY8D API 快速發送簡訊、管理範本與追蹤發送結果而設計。

## 產品定位

此工具適合需要日常批量發送簡訊、管理常用範本、確認發送狀態與追蹤操作紀錄的使用者。它提供 Windows 圖形介面，讓您不必自行撰寫 API 呼叫程式碼即可完成常見操作。

## 功能特色

- 支援單筆或多筆門號發送簡訊
- 支援立即發送與預約發送
- 可管理多筆常用簡訊範本，並儲存於 `templates.ini`
- 可檢視本機發送紀錄，並依門號、內容或批次號碼篩選
- 可查詢 EVERY8D 帳號餘額
- 可查詢電信端送達狀態
- 可取消尚未發送的預約簡訊
- 預設啟用 24 小時內相同內容的重複發送攔截
- 發送前顯示對象數量與預估扣點
- 會將帳號與密碼以簡易加密形式儲存於目前使用者的 Windows 登錄檔中

## 系統需求

- Windows 作業系統
- AutoHotkey 1.x
- 可連線至 EVERY8D API 的網路環境

## 安裝與使用方式

### 方式一：直接執行腳本

1. 下載或複製本專案內容，並保留 `ev8dmms.ahk`、`templates.ini` 與 `sms_log.txt` 位於同一資料夾
2. 確認電腦已安裝 AutoHotkey
3. 雙擊執行以下檔案：
   - ev8dmms.ahk
4. 第一次啟動時，系統會要求輸入 EVERY8D 帳號與密碼，之後會保存至目前使用者的登錄檔

若要清除已保存的帳密，可在主畫面按下「重置帳密」，程式會清除資料後重新啟動。

### 方式二：編譯為可執行檔 EXE

若您希望發給他人使用或方便在沒有安裝 AutoHotkey 的環境執行，請先將腳本編譯為 EXE。

## 編譯成 EXE 檔

本專案使用 AutoHotkey 語法，建議使用 AutoHotkey 1.x 與 Ahk2Exe 進行編譯。

### 方法一：使用 Ahk2Exe 圖形介面

1. 安裝 AutoHotkey 1.x
2. 打開 Ahk2Exe.exe
3. 選擇來源檔案：
   - ev8dmms.ahk
4. 指定輸出檔名，例如：
   - ev8dmms.exe
5. 按下「Convert」或「Compile」完成編譯

### 方法二：使用命令提示字元

若已安裝 Ahk2Exe，可直接在命令提示字元執行：

```bat
Ahk2Exe.exe /in ev8dmms.ahk /out ev8dmms.exe
```

若 Ahk2Exe 不在 PATH 中，請使用完整路徑，例如：

```bat
"C:\Program Files\AutoHotkey\Compiler\Ahk2Exe.exe" /in ev8dmms.ahk /out ev8dmms.exe
```

## 使用流程

1. 啟動工具後，確認目前帳號；可按「查詢餘額」確認可用點數
2. 填入手機號碼（多筆請以半形逗號隔開）
3. 選擇範本，或直接輸入簡訊主旨與內容
4. 確認字數提示後按「發送簡訊」
5. 在確認視窗選擇立即發送或預約時間，再按「確認送出」
6. 發送結果會寫入 `sms_log.txt`，可從「檢視紀錄」查詢、篩選或進一步操作

## 輸入與預約規則

- 每個門號必須為 8 至 15 位數字，可選擇以 `+` 開頭；台灣手機建議輸入完整 10 碼，例如 `0912345678`
- 門號之間只能使用半形逗號分隔，不可有連續逗號或結尾逗號
- 70 字以內視為 1 封；超過 70 字後依 EVERY8D 規則拆分，每 67 字計 1 封
- 簡訊內容最多 333 字；超過上限時無法發送
- 預約時間必須晚於現在至少 10 分鐘，且不可超過現在 6 個月
- 主旨僅供本機紀錄使用，不會發送給簡訊收件人

## 注意事項

- 發送簡訊會依照實際點數扣費，請事先確認帳號餘額
- 請確認手機號碼與內容無誤後再送出
- 帳密儲存於 Windows 登錄檔，請勿在不受信任的共用 Windows 帳號下執行
- `templates.ini` 與 `sms_log.txt` 會以程式所在資料夾為基準讀寫，編譯成 EXE 或搬移程式時請一併保留資料檔
- 若要部署給其他使用者，建議提供編譯後的 EXE 檔，而非原始 .ahk 檔
- 本工具依賴 EVERY8D API，若 API 服務異常可能影響發送與查詢功能
