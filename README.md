# EVERY8D 簡訊發送工具

EVERY8D 簡訊發送工具是一套基於 AutoHotkey 開發的 Windows 桌面應用程式，專為透過 EVERY8D API 快速發送簡訊、管理範本與追蹤發送結果而設計。

## 產品定位

此工具適合需要日常批量發送簡訊、管理常用範本、確認發送狀態與追蹤操作紀錄的使用者。它提供一個直覺的圖形介面，讓您不必自行撰寫 API 呼叫程式碼即可完成常見操作。

## 功能特色

- 支援簡訊發送
- 支援預約發送
- 可管理多筆常用簡訊範本
- 可檢視本機發送紀錄並依關鍵字篩選
- 可查詢帳號餘額
- 可查詢電信端送達狀態
- 可取消已預約的簡訊
- 可自動過濾 24 小時內重複發送的相同內容
- 會將帳號與密碼加密儲存於 Windows 登錄檔中

## 系統需求

- Windows 作業系統
- AutoHotkey 1.x
- 可連線至 EVERY8D API 的網路環境

## 安裝與使用方式

### 方式一：直接執行腳本

1. 下載或複製本專案內容
2. 確認電腦已安裝 AutoHotkey
3. 雙擊執行以下檔案：
   - ev8dmms.ahk
4. 第一次啟動時，系統會要求輸入 EVERY8D 帳號與密碼，之後會自動保存

### 方式二：編譯為可執行檔 EXE

若您希望發給他人使用或方便在沒有安裝 AutoHotkey 的環境執行，請先將腳本編譯為 EXE。

## 編譯成 EXE 檔

本專案使用 AutoHotkey 語法，建議使用 AutoHotkey 1.x 與 Ahk2Exe 進行編譯。

### 方法一：使用 Ahk2Exe 圖形介面

1. 安裝 AutoHotkey 1.x
2. 打開 Ahk2Exe.exe
3. 選擇來源檔案：
   - ev8dmms.ahk
4. 指定輸出檔名，例如：
   - ev8dmms.exe
5. 按下「Convert」或「Compile」完成編譯

### 方法二：使用命令提示字元

若已安裝 Ahk2Exe，可直接在命令提示字元執行：

```bat
Ahk2Exe.exe /in ev8dmms.ahk /out ev8dmms.exe
```

若 Ahk2Exe 不在 PATH 中，請使用完整路徑，例如：

```bat
"C:\Program Files\AutoHotkey\Compiler\Ahk2Exe.exe" /in ev8dmms.ahk /out ev8dmms.exe
```

## 使用流程

1. 啟動工具後，先輸入或確認帳號資訊
2. 填入手機號碼（可一次輸入多筆，請以半形逗號隔開）
3. 選擇或建立簡訊範本
4. 輸入簡訊內容與必要主旨
5. 點選發送，系統會先顯示確認視窗
6. 發送結果會記錄於本機紀錄檔，您可後續查詢狀態

## 注意事項

- 發送簡訊會依照實際點數扣費，請事先確認帳號餘額
- 請確認手機號碼與內容無誤後再送出
- 若要部署給其他使用者，建議提供編譯後的 EXE 檔，而非原始 .ahk 檔
- 本工具依賴 EVERY8D API，若 API 服務異常可能影響發送與查詢功能
