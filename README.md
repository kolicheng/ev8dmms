# EVERY8D 簡訊發送工具

EVERY8D 簡訊發送工具是一套基於 AutoHotkey 開發的 Windows 桌面應用程式，專為透過 EVERY8D API 快速發送簡訊、管理範本與追蹤發送結果而設計。

## 產品定位

此工具適合需要日常批量發送簡訊、彈性自訂常用範本、確認發送狀態與追蹤操作紀錄的使用者。它提供直覺的 Windows 圖形介面，讓您不必自行撰寫 API 呼叫程式碼即可完成所有簡訊收發操作。

## 功能特色

- **單筆 / 多筆群發**：支援單一或多個手機門號批次發送（以半形逗號分隔）
- **即時 / 預約發送**：在送出確認視窗明確選擇立即或預約發送；預約須至少 10 分鐘後、且不超過 6 個月
- **自訂範本管理**：內建「範本管理」視覺化介面，使用者可在操作中隨時新增、修改或刪除範本，無需手動建立設定檔
- **自動產生資料檔**：本機未偵測到 `templates.ini` 或 `sms_log.txt` 時，程式會於執行時自動初始化建立
- **發送紀錄與送達追蹤**：本機發送紀錄獨立保存，可依門號、主旨、內容或批次號碼即時篩選，並能查詢電信端送達狀態與取消未執行的預約
- **帳號與餘額管理**：一鍵即時查詢 EVERY8D 剩餘可用點數；支援重置帳號密碼
- **資安保護**：帳號與密碼以簡易加密形式儲存於目前使用者的 Windows 登錄檔（HKCU），不寫入明文檔案
- **防呆與過濾機制**：
  - 24 小時內相同門號與內容重複發送自動攔截
  - 發送前顯示門號數量與預估扣點確認
  - 簡訊字數與長度動態統計（支援超過 70 字拆則計費提示，上限 333 字）
- **隱私安全**：專案設定已將所有 `.txt` 與 `.ini` 排除於 Git 追蹤之外，避免個人範本與客戶發送紀錄被推送到版本控制庫

## 系統需求

- Windows 作業系統 (Windows 7 / 10 / 11)
- AutoHotkey 1.x（若直接執行 `.ahk` 原始碼需安裝；若使用編譯後的 `.exe` 則免安裝）
- 可連線至 EVERY8D API 的網際網路環境

## 安裝與執行方式

### 方式一：直接執行腳本（開發 / 免編譯）

1. 下載本專案的 `ev8dmms.ahk`
2. 確認電腦已安裝 [AutoHotkey 1.x](https://www.autohotkey.com/)
3. 雙擊執行 `ev8dmms.ahk`
4. 第一次啟動時，系統會要求輸入 EVERY8D 帳號 (UID) 與密碼 (PWD)，確認後會加密保存於 Windows 登錄檔

> **提示**：您**不需要**手動準備 `templates.ini` 或 `sms_log.txt`。程式在首次啟動與發送時，會自動在腳本同層目錄建立所需的檔案。

若需清除或更換帳號密碼，可在主畫面點擊「🔑 重置帳密」，清除後重新輸入即可。

---

### 方式二：編譯為獨立可執行檔（EXE，推薦分發使用）

若要分發給其他同仁或在沒有安裝 AutoHotkey 的電腦上執行，可將其編譯為單一 EXE 檔：

#### 方法 A：使用 Ahk2Exe 圖形介面
1. 開啟 AutoHotkey 安裝目錄下的 `Compiler\Ahk2Exe.exe`
2. **Source (script file)**：選擇 `ev8dmms.ahk`
3. **Destination (.exe file)**：設定輸出路徑，例如 `ev8dmms.exe`
4. 點擊 **Convert** 完成編譯

#### 方法 B：使用命令列編譯
```bat
"C:\Program Files\AutoHotkey\Compiler\Ahk2Exe.exe" /in ev8dmms.ahk /out ev8dmms.exe
```

編譯完成後，只需將 `ev8dmms.exe` 放置在任一資料夾即可獨立執行。

### 範本管理說明
- **隨增隨用**：本程式無須預設範本即可正常運作。您可以在日常使用時，隨時點擊主介面的「**⚙️ 範本管理**」開啟管理子視窗。
- **新增 / 更新**：輸入「範本名稱」與「範本內容」，點擊「💾 新增 / 更新」即可永久儲存至 `templates.ini`，並立即同步回主介面下拉選單。
- **刪除**：在清單中選取不要的範本，點擊「❌ 刪除所選」即可移除。

## 操作使用流程

1. **檢查帳號與餘額**：
   啟動程式後，介面會顯示當前登入帳號，可點擊「💰 查詢餘額」確認點數餘額。
2. **輸入手機號碼**：
   在「手機號碼」欄位輸入目標號碼。若要發送多筆，請以半形逗號隔開（例如：`0912345678,0923456789`）。
3. **選擇範本或自行輸入內容**：
   - 可直接在「簡訊內容」中鍵入文字。
   - 或從「選擇簡訊範本」下拉清單選擇預存內容（亦可隨時按「⚙️ 範本管理」新增範本）。
   - 「簡訊主旨」為選填欄位，僅供本地發送日誌註記，不會發送給收件客戶。
4. **確認字數與扣點預估**：
   輸入內容時下方會即時計算字數：
   - 70 字內：計為 1 封簡訊。
   - 71～333 字：每 67 字拆分為 1 封簡訊計費。
   - 超過 333 字：超過系統上限，發送按鈕將自動鎖定以防送出失敗。
5. **送出確認與發送設定**：
   點擊「🚀 發送簡訊」後會跳出確認視窗，顯示發送對象數量與預估總扣點。在此視窗可選擇：
   - **立即發送**：預設選項，日期與時間欄位停用，確認後立即送出。
   - **預約發送**：選取後啟用日期與時間欄位，預填未來時間；須至少晚於確認當下 10 分鐘，且不超過 6 個月。時間不合規時保留視窗供修改，不會改成立即發送。
6. **檢視紀錄與狀態追蹤**：
   點擊主介面「📜 檢視紀錄」可開啟歷史紀錄視窗：
   - 支援依門號、主旨、簡訊內容或批次號碼快速搜尋篩選。
   - 選取紀錄後可點擊「🔍 查詢送達狀態」向電信端查詢實際收件狀態。
   - 若為尚未執行的預約簡訊，可點擊「🚫 取消預約」撤銷發送。

## 輸入與格式規則

- **門號格式**：每個門號長度需介於 8 至 15 碼數字，可帶開頭 `+` 號；台灣手機請輸入完整 10 碼（如 `0912345678`）。
- **門號分隔**：多筆門號之間僅限使用半形逗號 `,` 分隔，系統會自動剔除空格與連續或結尾逗號。
- **重複發送攔截**：預設啟用 24 小時過濾機制，若相同號碼在 24 小時內已發送過完全相同的簡訊內容，系統將會主動攔截並跳出警告提示。

## 注意事項與安全性

- **簡訊資費**：簡訊送出後將依照電信業者與 EVERY8D 方案扣點，大量群發前請確認號碼與內容正確性。
- **帳密安全**：帳號密碼存放在本機使用者登錄檔（`HKCU\Software\Every8DSMSTool`），請勿在非信任的共用 Windows 使用者帳戶下操作。
- **版本控制保護**：`templates.ini` 與 `sms_log.txt` 涉及個人業務常用範本與客戶通訊隱私，專案預設已將其加入 `.gitignore`。請勿將包含真實資料的檔案推上公開版本控制庫。
- **攜帶與搬移**：若要將程式與現有範本、發送紀錄移至其他電腦，只需複製程式檔案以及同目錄下的 `templates.ini` 和 `sms_log.txt` 即可。
